# koshnichka-data

Данни за приложението **Кошничка** (седмично меню + списък за пазаруване с цени от българските вериги).

Всеки ден GitHub Actions:
1. взима цените по магазини от отворените данни на КЗП „Колко струва“ (обработени от [smartbasket-data](https://github.com/Rumbarski/smartbasket-data));
2. намира продуктите за рецептите във всяка верига и смята медианни цени по град;
3. проверява данните (`build/validate.py`) — при съмнителни данни **не** публикува и GitHub праща имейл;
4. записва `docs/data.json` и `docs/index.html` (самото приложение).

Приложението: **https://stoyanyanev044-boop.github.io/koshnichka-data/** (GitHub Pages от папка `docs/` в `main`)

## Файлове
| | |
|---|---|
| `build/ingredients.py` | съставки → категории и правила за разпознаване в КЗП |
| `build/recipes*.py`, `build/steps_*.py` | рецептите и стъпките |
| `build/build_data.py` | сглобява `data.json` |
| `build/validate.py` | проверки преди публикуване |
| `docs/photos/<id>.jpg` | снимки на ястията (по желание) |

Ръчно пускане: **Actions → Ежедневни цени → Run workflow**.

## Известни рискове
- Зависим от публичния клон `data` на smartbasket-data. Ако спре, проверката хваща остарели данни (>7 дни) и спира; тогава трябва собствена обработка на архивите на КЗП.
- КЗП покрива ~101 вида основни продукти — без брошури/промо асортимент (етап 2).
